## Reproducible build

```sh
npm ci
npm test                       # builds root + www first, then Node tests
npx cap sync ios
npx cap sync android
```

`www` is Capacitor's payload. `scripts/build-web.mjs` copies root web sources into `www` and packages the pinned MediaPipe Face Mesh JS/WASM/data under `vendor/face_mesh` in both targets. Generated vendor assets are ignored by Git; **run `npm ci && npm run build` before Capacitor sync or web deployment**. Do not sync stale `www`. Firebase writes and AdSense are disabled; all scores are local. Browser web hosting and native must ship the same privacy text. `ads.txt` remains only at web root for legacy hosting; no ads are loaded.

For Android, use JDK 21 and Android SDK 36. Those tools are not installed on this Mac as of October 9, 2026; GitHub Actions supplies them for candidate compilation. `cd android && ./gradlew assembleDebug bundleRelease` produces a debug APK and **unsigned** release AAB. Debug APK uses Gradle's local debug key, not a store credential. Never upload either artifact as a release without owner review.

For iOS, point `DEVELOPER_DIR` to full Xcode and run `xcodebuild -project ios/App/App.xcodeproj -scheme App -configuration Debug -sdk iphonesimulator -destination 'generic/platform=iOS Simulator' -derivedDataPath build/ios CODE_SIGNING_ALLOWED=NO build`. This yields an unsigned simulator `.app`, **not** an installable iPhone IPA.

## Branding assets

Original navy/cyan/coral eye-and-stop mark is generated by `scripts/generate-native-art.py` (Pillow required; install into a local virtualenv). It writes iOS app icon and launch splash, Android legacy/round/adaptive icons and portrait/landscape splash PNGs, plus web manifest icons. Re-run after changing the generator, then `npm test && npx cap sync android && npx cap sync ios`. Review launcher masking and splash framing on physical phones before approving store artwork. The generated native PNGs live in `ios/App/App/Assets.xcassets` and `android/app/src/main/res`; `icons/` and `www/icons/` serve the web/PWA.

## QA matrix (real device gate)

On at least one supported iPhone and Android phone, repeat each item in all five modes (Classic, Precision, Endurance, Daily, Surprise):

- Fresh install offline: menu, local inference assets and camera prompt work without network. Verify permission allow and deny, return to device settings, then retry. Denied message stays visible; no blank screen.
- Center face in ordinary lighting, finish 3s calibration with open eyes, blink: timer stops. Compare quick wink vs long closure; no false completion with face out of view. Try glasses, different skin tones, front camera orientation, low light.
- Lock/background while permission prompt, calibration, or round is active; return to menu with camera indicator off. Retry, navigate Menu, repeat quickly; no stale calibration or duplicate camera stream.
- Endurance completes at 30s without externally hosted video. Save a score with text and punctuation; confirm local ranking survives relaunch and name never renders as HTML. Share/copy and Save Selfie (including native file location/permissions) must be explicitly verified.
- Small phone/large font/VoiceOver/TalkBack/landscape: controls, error, and policy links reachable; no clipped status bar or home indicator. Check privacy and Terms links in native WebView.
- Inspect network on real devices: camera frames must not leave device; candidate uses system fonts (no Google Fonts request), no Firebase/AdSense calls. Test offline after install and after app update. Check thermal load and battery during sustained inference.
